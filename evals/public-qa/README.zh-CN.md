# 公开基准适配器
[English](README.md) | [简体中文](README.zh-CN.md)

这些是独立运行的评测脚本，不是日常启动依赖；不会重启或修改正在运行的 Amadeus 服务。请从仓库根目录执行，使用独立结果目录和 Python 虚拟环境。

## 当前真正接通的链路
- **BFCL V4**：固定抽取 Python 单工具、多工具选择、并行调用、不相关工具四类题。每题只采集一次模型响应。Amadeus 使用真实 Runtime 构造上下文；smolagents 1.26.0 使用原生 ToolCallingAgent 提示。双方走相同模型传输层和相同归一化工具 schema；不执行题目描述的函数。函数名的点映射为下划线，评分按官方规则处理。
- **LongMemEval-S**：去掉答案和证据标记，给双方完整的带时间历史，比较回答。本轮用下载的原版快照。**不是自动记忆入库、持久化检索或遗忘机制测试。**
- **GAIA**：验证集 165 题中固定抽取六道无附件题，原生多步循环共用 DeepSeek 连接及公开搜索／网页读取。尚未覆盖全部 165 题、38 道附件题、交互浏览器和代码执行。
- **SWE-bench Verified**：一个真实样本 pylint-dev__pylint-7277，按任务 ID 哈希确定。双方在独立离线 Docker 容器中读写代码和运行测试；官方 eval.sh 与评分器判分。先确保原始代码失败、官方参考补丁通过。**不是完整 500 题成绩。**

smolagents 保留原生提示和 GAIA/SWE 原生循环，但模型 API 经过共享 broker，未使用它默认的 Provider SDK。双方 tool_choice 为 auto。因此这是受控接入对比，不是两个默认产品的开箱对比。

## 使用
详细命令见[英文操作说明](README.md#setup)。依赖放独立 venv：smolagents==1.26.0、unidiff==1.0.1；数据准备另需 pandas、pyarrow 和 PyYAML。公开数据、官方源码和容器不放应用仓库。密钥只由宿主模型连接读取，不进入被测代码容器。

原始输出预算为 4,096 token，16K 复测独立存放；不得覆盖首轮结果。每个 solver attempt 先写 started 记录，有记录就不静默重跑；中断且结果缺失记为未完成／未知。新试验用新目录，同一结果目录不可同时启动多个 runner。

## 判分边界
- 无价格配置时，费用必须未知；失败响应没有 usage 时，已记录 token 只是下界。缓存输入属于输入总量，不能重复相加。搜索服务的额外用量也应计入。
- 空答案或缺失 final_answer 参数，先判交付失败，不能让 LLM 把空白误判为正确。
- 严格官方分数与语义复核分开保留，不能为了提高成绩改参考答案。
- 首轮 SWE 适配遗漏项目记录，安全门控正确隐藏执行工具；这类记录属于适配无效，不能算 Agent 编码能力失败。修正版建立独立项目，并在调用模型前检查工具是否真正可用。
- 评测脚本不是生产功能变更，一键启动、首次启动无需增加这些依赖。
