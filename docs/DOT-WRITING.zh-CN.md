# Dot 写作面板和 Windows 应用输入辅助

在桌面版打开 **View → Floating personal agent**，展开右侧标签并选择本地 Dot 会话。聊天、语音和截图仍在「聊天」页。写作工具共用当前窗口中的原文。选中一段可只处理该段，未选中时处理全文。「读者反馈」可选受众，「翻译」可选目标语言，「来源核对」需填入参考资料。点击对应动作生成结果，改写类结果可采纳、忽略或撤销。收起再展开会保留草稿，切换绑定会话或关闭 Dot 会清除工作稿。

## 在其他应用里使用

1. 在 Dot 右侧选择「应用辅助」。选择「补完当前句」「续写下一段」或「语法修正」，再点「选择应用…」选择目标应用的 exe。
2. 核对应用路径、模型和服务地址后允许。每个应用可单独授权或停用，授权持续到本次辅助窗口关闭。设置窗口可以最小化。
3. 回到目标编辑框继续打字。停顿后，如果有候选，屏幕边缘会出现提示。十秒内按 Tab 可采纳。切换焦点或继续修改会使旧候选失效。
4. 修改 Dot 绑定、模型或服务地址后，重新授权目标应用。

发送给模型的范围为当前行光标前最多 512 个字符，可能产生模型费用。仅在用户授权的应用中检查焦点，不保存键入记录。密码框、只读框、不能确认保护状态的控件和已有选区都会跳过。

支持 Win32 标准 Edit、RichEdit，以及能提供光标范围和定向写回的 UI Automation 普通编辑框。后者支持在不超过 2,000 个字符的文本框末尾使用。自绘编辑器、终端和部分富文档窗口可能缺少接口，可将所选文字粘贴到 Dot 写作面板。候选可见时临时注册 Tab，快捷键被其他软件占用时会显示提示。要求本机可运行 Windows PowerShell 和 .NET Framework。
