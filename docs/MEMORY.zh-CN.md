# 记忆、知识库与检索

当前说明核对日期：2026-10-06。

## 管理召回范围

存储范围（普通对话或某一个项目）与召回范围（仅原对话／本范围共享）分开管理。可搜索原对话标题、按原对话及召回范围组合筛选，也可一键查看当前对话的记忆。手动创建默认收起，并预选当前符合范围的原对话；不列出内部子任务或其他项目的对话。

选择全部筛选结果后，可批量设为**仅各自原对话**、**本范围共享**或**恢复自动范围**，总选择数不限、请求顺序分批。每条局部记忆保留各自原对话，不改写来源，也不顺带启用候选或已停用记忆。版本已变化或共享后存在冲突的条目会单独失败；没有原对话记录的条目不能凭空绑定原对话。

自动范围按类型生效：事件和普通对话决定留在原对话，偏好、经验和项目决定在存储范围内共享。手动覆盖一直保留，直到选择恢复自动。创建时显示实际生效范围；手动创建局部记忆必须选择同范围原对话。本次界面改进不会批量迁移旧记录或自动扩大它们的范围。

## 范围与开启

普通对话共享用户记忆，每个项目有自己的记忆。自动管理保持项目／普通范围分开；主动混入用户记忆属于单独选择。范围默认设置供新对话继承，单个对话可覆盖；不会暗中为旧对话开启。更换提取模型目标需重新授权。

自动管理同时开启提取与召回。空闲两分钟后，从最多 30 条近期用户消息（各 4,000 字符）和 80 条同范围记忆提取，不发送助手／工具正文和附件。关闭会丢弃进行中的结果。明确有来源的偏好、决定、事件可激活；模糊冲突和手工记录不盲目覆盖。经验需要适用条件与同范围成功宿主证据。

## 历史与图谱

条目带生效时间、来源、修订及可选实体／属性／值。精确重复可合并；明确更新的同属性自动事实可替代旧自动记录，新证据可重新判断争议。相似度本身不能决定身份或真假。

确认过的别名及有来源的有向关系支持时间查询，最多三跳／40 条路径。引文匹配证明来源，不证明蕴含或因果；过期、删除、失效来源退出检索。遗忘删除应用条目、向量和修订，并阻止同来源再生，不等于擦除备份或 SQLite 空闲页。

可选文档图谱提取使用已选模型目标，每文档最多八块／14,000 字符。标签与关系需出现在引文中；复用同范围精确实体，拒绝歧义别名。这是有界提取，不是无限本体自学习。

## 文档与版本

普通对话可读取共享资料库及其私有会话文档；项目不自动加入普通范围。子任务继承授权父范围，不作为普通会话条目塞入范围选择器。

可上传文档或登记文件夹。自动维护按内容创建版本、保留引用、使删除／失效旧源退出检索，并复用未变化文档。私有会话上传不自动共享，不同路径仅同名不算同版本。见[文件夹导入](knowledge-import-resilience.zh-CN.md)。

## Embedding 与 ANN

可选本地 multilingual-e5-small ONNX q8（384 维）或兼容 embedding API。本地首次下载模型，之后使用经过校验的磁盘缓存；查询和正文采用不同 E5 前缀。本地提取／向量化／检索不代表回答也在本机：召回片段仍可能发给对话 LLM。外部索引向选定端点发送授权分块／查询。

FTS 与向量候选经倒数排名融合和标题重排。少于 2,000 个向量使用精确相似度，更大候选集用 HNSW。SQLite 为权威数据；最多四代派生 ANN 缓存按内容／范围／模型与哈希验证。少量精确近邻校准可把 ef 从 256 调到 512/1024，或回退精确检索。它测近似检索保真度，不测语义质量。

本地记忆自动索引、已授权文档自动维护不需逐文档点击；批量索引用于补齐当前范围。更换目标需重新保存范围授权。外部记忆索引仍保留明确控制。

## 恢复与质量

临时失败退避重试，配置错误三次后暂停。同目标凭据变化或“修复后重新检查”可安全再试。失败安装走普通审批下的诊断，不自动重放。

用户标注检索样例可比较全文／混合策略；自动选择要求至少 15 例、五例留出和 0.1 MRR 提升，排除 Agent 自标注。不会自动搜索新模型、重排器或分块参数。历史四查询 E5 小样本有 3/4 首位正确，并暴露跨语言错误，不能当作大库质量结论。

## 管理不断增长的记忆列表

记忆页默认显示当前条目，区分有效、候选、已停用、冲突和历史／过期。支持按内容、主题、来源搜索，每页 25 条；可选择本页或逐条勾选，总选择数不设上限，按每批 100 条顺序提交并显示进度。支持确认、停用和忘记；忘记会再次确认，沿用来源排除机制。每条独立校验范围和版本，某条失败不影响其他成功项。冲突、过期及已替代的条目不能批量批准。

模糊冲突明确显示数量，提供直接筛选入口，并展示相互冲突的内容和来源。未解决前不进入召回，不自动打断任务或选择胜出说法。

已开启的后台学习改为按上次成功位置增量处理用户消息，每批最多 30 条，不再反复提取近期同一段历史。同范围的结构化事实项和值相同则复用；完全重复的候选可归并，但不会因此激活，保留来源和修订历史。原对话开启自动管理后旧候选可按来源复审，不会无条件全部批准。可使用现有范围默认开关，为新对话和继承设置的对话开启自动管理；对话级例外、项目与普通对话隔离继续保留。本次没有新增外部数据发送目的地。

## 召回范围与衰减

存储范围、召回范围和衰减规则彼此独立。情节及普通对话决定默认仅在原对话召回；偏好和项目决定默认在已有普通对话／项目范围共享。新建议保存原对话标识，旧条目从结构化引用解析；来源不明的局部记忆不召回。改为共享需用户编辑，仍不能跨项目。新对话不会召回另一对话的局部情节；同一对话内切换任务，目前不会自动猜测新场景边界。

自动衰减保持偏好、项目决定和有证据的经验稳定；情节及普通对话决定采用：权重 = 0.5^(经过天数/30 + 后续用户轮次/100)，最低 0.05。用户可覆盖为不衰减、仅时间、仅轮次或两者结合，并设置半衰期。工具调用、token 数和记忆读取不算轮次，也不会刷新年龄；缺少轮次证据不加轮次惩罚。权重仅影响排序，不是真实性评分或自动删除；明确过期的记录仍退出召回。

自动分类沿用提取器的通用记忆类型，不使用话题关键词特例。错误分类的旧记录可能需要修正。本次部署不会自动发起付费历史重分类或破坏性清理。

## 可读图谱管理

系统 memory:<id> 节点表示来源，不代表人物或概念。默认隐藏内部节点，展开时用记忆摘要显示；手工创建折叠到高级设置，关系支持搜索和分页。修订记忆同步系统来源引用，停用使来源关系退出当前查询，检索检查过期；忘记时清除已无关系引用的内部节点。不会自动重写无关的实际实体关系。证据失效或缺失会明确提示并退出遍历。来源连线不等于实体消歧或事实推理。

列表优先展示来源对话标题、日期、召回范围和衰减规则；ID 和修订号保留在技术详情。不带具体对话的范围搜索排除局部记忆；它们仍可在管理列表查看，并在原对话召回。

“已启用”表示允许按需召回，不是每次都放入上下文，也不是已验证为真。实际召回还取决于范围、相关性、过期和衰减。手动确认启用候选，重新启用恢复用户停用的条目。缺少明确生命周期元数据的旧候选仍保留为候选，不猜测当时意图。

## 旧候选自动复审

原对话需未归档、空闲且开启自动管理，沿用该对话已授权模型连接。每批最多复审 8 条候选及对应用户原文，每条原文最多 12,000 字符，不发送附件或工具输出，会消耗模型额度。候选版本、来源、模型和有效记忆集指纹不变时不反复复审；失败或中断不盲目重放付费调用。

宿主核对原文引用、版本、授权、过期、冲突及经验证据后才启用。已停用、冲突、历史、过期和已忘记条目不自动恢复；不能定位原文的仍需人工核实。来源、模型或有效记忆变化可触发重新考虑。启用只代表可按需召回，不是证明为真。在另一对话开启自动管理，不会批准整个项目所有候选。本次不需要新增依赖或修改首次启动。

## 适用条件与范围例外

召回附带适用条件、匹配信号和同键冲突；相关性不是经过校准的真实性概率。仅当结构化实体、属性、适用条件完全对应时，更具体的原对话或项目记录才会在本次上下文中遮蔽宽泛偏好，不删除或改写原记忆。条件不同的记录仍分别保留，需要按当前要求核实。同优先级的不同值显式标出冲突，不静默选一个。范围授权、来源与有效期检查先于此选择，项目不会因此自动启用用户偏好。

### 经验验证项

检查加入计划，通过 resolve_memory_check 关联当前已完成的 verify 任务及版本绑定
证据，或记录不适用原因。结果留痕，不据此增加置信度，不自动激活或共享记忆。
关闭记忆、修改记忆版本或变更范围后，旧条目不再进入上下文。候选仍是待核实假设，
不会静默升级。规划、检查选择和不适用判断仍依赖模型；尚未实测缺陷率下降。
应保留原验收约束及回归测试；删除功能属于范围减少，不能算作修复。

已召回经验的待验证项会阻止最终完成，直到关联当前检查或明确记录不适用原因。运行时仅提供有限纠正步骤，不重放历史操作。

### 启用本次更新

无需新增依赖、下载模型或迁移数据库。现有启动脚本的源码指纹已覆盖本次后端改动。任务结束并停止服务后运行 Start-Amadeus.cmd；首次安装仍使用 First-Start-Amadeus.cmd。打开已有进程不会加载新后端代码。原有记忆保留，只有符合条件的经验被召回时才建立验证项。

经验处置现在记录已声明任务契约的指纹（验收条件、依赖、产物及输入输出声明）。增加、移除或修改契约会重新打开旧的不适用/检查判断，仅执行状态变化不会触发。没有指纹的旧处置也需复核。这是本轮结构变化检测，不是语义弱化判断或跨会话契约丢失检测。结果事件保留记忆修订和契约指纹供审计，不证明因果收益。

### 有证据的学习复核

- `propose_verified_experience` 要求本轮有类型记录的已执行失败，以及随后针对当前产物版本成功的 verify 任务。预期/观察行为、原因假设与产物和事件引用一起留存。只创建未生效、原会话可见的候选，不自动成为因果规律或共享记忆；行为描述和原因仍需复核。
- `compare_acceptance_contracts` 比较同一对话更早的主任务与当前计划，列出新增、移除、改变的契约。按任务 ID 匹配，改名显示为移除和新增；仅检测结构变化，不判定语义弱化，也不授权删减需求。
- `inspect_learning_outcomes` 汇总本对话最近最多 100 轮的当前可见经验处置及已有策略评估。更换轨迹、错误消失和有记录的进展分别统计；关闭记忆不返回统计。它不计算避免漏洞数、校准置信度或因果收益，也不自动修改路由或权限。

### 检索诊断与图谱自动化（2026-10-11）

知识检索采用 SQLite 词法检索与可选本地/API 向量；有效向量少于 2,000 时精确查询，否则使用 HNSW。默认是自研分块检索管线；可选本地服务已接入 LightRAG。本地 multilingual-e5-small 为 384 维，已加 query/passage 前缀。目前默认未启用 cross-encoder；可选本地服务支持重排；按字符分块仍可能超过本地 tokenizer 预算。

混合检索保留各路名次、原始分与 RRF 累计贡献，不再用名次覆盖融合分；标题加权独立展示。分数不是校准概率，仍可能返回不相关候选。同源引用只匹配已召回候选中空白归一化后完全相同的分块，不等于任意其他文档，也不是全库查重。空查询不返回候选。

已授权的资料文件夹关系提取本来就会自动启用有原文支持且无歧义的关系（限前 8 块／14,000 字符）。重名歧义现在单独记录为延后处理，不再阻塞其他有效关系。提案工具复用同范围唯一的已确认实体及已有别名；新别名、重名匹配仍需核实。原文共现不等于语义事实。本次不增加外部调用或扩大授权范围。

可选本地服务现在提供分窗 embedding、cross-encoder 与 LightRAG；详见 [本地检索](LOCAL-RAG.zh-CN.md)。后续仍需中英留出评测和拒答阈值校准。单纯更换向量库或改成 1024 维不能证明相关性改善。

### Agent 的统一检索统计入口

核心只读工具 `inspect_retrieval_status` 仅统计当前对话获准访问的知识库范围和可见记忆。返回当前/保留文档数、分块数、正文 UTF-8 字节数、向量覆盖率和维度、缺失/旧模型/无效向量数、导入状态，以及记忆状态与可召回数量。不会返回正文、密钥、其他对话的私有记忆或全局数据库总量。向量序列化字节数、float32 理论容量不等于磁盘或内存占用；无法按范围归属的数据库大小和远端集合总量明确标记为未知。

空检索诊断区分未启用、未导入、导入失败、等待导入、无可检索分块、仅词法检索、索引未完成、维度混用和索引齐全但未命中。索引齐全不代表结果相关或事实正确。

索引建议不会执行变更。内置策略仍为有效候选不足 2,000 时精确检索，否则 HNSW。`memoryBudgetMiB` 仅用于建议，不修改设置。IVF 需要代表性训练数据及参数调优；PQ 属于有损压缩，需要评估召回损失。不会因数量阈值自动切换后端、下载模型、探测网络或重建索引；配置状态与服务已验证状态分别呈现。

### 图谱发现与来源关系

图谱工具区分语义实体和记忆来源节点。旧 memory:ID 自动显示来源摘要，无需改名，不编造别名。搜索匹配名称、中英词项和当前有权查看的原文证据；list_memory_entities 返回分页及当前范围数量。失效、已被取代和对话无权读取的记忆来源在查询时过滤；保留历史不代表当前有效。空结果区分没有可见图谱、没有匹配节点及节点没有可用边。来源关系不冒充语义事实。已有授权文档抽取与可选 LightRAG 属于独立的知识库图谱流程。

自动管理会在空闲周期通过该对话已授权的模型连接，每批最多补齐四条有效记忆的实体关系。名称、关系与引用须同时出现在记忆和用户原文中；实体歧义保留待处理，中断调用不自动重放。自动实体失去有效证据后退出当前结果。同一主题不再直接判为矛盾：单值事实按实体、适用条件和不同值判定，多值记录可以并存。旧自动冲突进入来源复审，必须明确判为可并存才解除；用户停用记录保持停用。这是有原文检查的模型抽取，并非语义正确性的证明。

### 检索质量与调查

默认搜索全部授权文档；documentIds 只限定当前追查，在词法和向量候选选择前过滤。两路候选池各最多 60 条。新导入使用约 600 字符窄块，长行有重叠（字符限制不是精确 token 保证）。旧大块不破坏性重建：重排选择最多三个与查询相关的 600 字符窗口，保留偏移和原始引用，尾部相关内容可单独评分。

自动相对分差截断至少保留两条；短列表、平坦分数和非 0–1 分数保守保留，返回被收起候选的 ID 和分数。它是启发式，不是校准后的相关概率，高分无关候选仍可能保留。结果默认未判定；Agent 可用 assess_retrieval 记录证据是否充分及缺口，但不获得验证通过资格。每次调查最多四个去重查询、60 秒预算，连续两轮无新证据停止；不等同于整段对话的总预算。最近 500 份查询轨迹在本地保留候选哈希、配置身份及排序；Agent 的轨迹工具不返回其他对话的查询原文。轨迹支持审计，不保证模型逐位复现，也不能证明资料完整。

## 冲突记录一致性修复

创建和编辑记忆都会保存实际冲突对象 ID。排除自身、跨存储范围、跨原对话分区、失效和不存在的对象；互相处于冲突状态的有效关联仍保留，不能因为双方退出召回就丢失冲突。

主服务启动时本地核查当前冲突记录。能够确定对象时补齐关联；找不到当前对象时改为待确认，并记录人工复核标记。修复始终保持不参与召回，不调用模型，不修改原文或删除历史；修订历史记录修复前后状态。相同状态再次启动不重复修订。历史或过期记录不自动恢复。

带人工复核标记的记录不会被候选自动复审或自动冲突消解启用；需人工确认或明确裁决。界面显示待复核原因，不再以空白“与以下记忆冲突”冒充已知矛盾。

新增自动学习与候选复审会独立判断适用范围：仅原对话、跨对话适用或不明确。不明确时限于原对话，不再仅凭“偏好”类型共享；仍遵循事件、普通对话决定的本地规则。手动范围选择优先。历史记录保留原范围，界面明确标记尚未单独复核，不批量重写或自动启用。
