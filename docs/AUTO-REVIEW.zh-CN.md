## 判断流程

工具守卫先判断是否需要审批；自动模式才调用独立、无工具的审核模型。带执行元数据、无参数的精确 cd 有狭窄快捷规则。关键词风险匹配交给独立审核；显式 ask 规则与 forceHuman 仍需人工。

宿主只接受结构验证通过的有限低风险操作（明确或隐含授权），或具明确／必要任务授权的中风险操作；都需已知影响、有效用户消息引用，且没有敏感数据／安全设置变更标记。高风险按下述明确授权及恢复证据评估；严重或补证后仍未知的风险交给用户。操作、配置或授权上下文变化会使判断失效。

## 证据与隐私

同一对话模型连接可接收先前文件观察及最多六个范围内字面路径／包／测试脚本候选：每文件读取最多 128,000 字节，发送摘录最多 12,000 字符，附哈希与截断标记。npm 的前置／主／后置脚本及本轮近期命令观察可作为依据，但不穷尽导入依赖和测试发现。

另选审核连接不会自动接收代码或命令日志。源码是不可信数据，不是审核指令。审核后再次核对文件哈希，但这不是文件系统锁。宿主命令按真实宿主文件／网络权限描述，不套用原生隔离后端的限制。

## 失败与用户决定

准备、服务商、无效响应、时限和取消分别记录；任何失败都不授权，不暴露原始服务商错误正文。卡片区分缺授权、进程归属、证据不全和审核器不可用。按宽泛进程名清理仍需人工判断范围，工作目录不是进程边界。

用户可仅允许一次、拒绝，或补充约束要求其他方案。其他方案会拒绝原操作并交回模型重新规划，不会暗中改写命令执行。审批等待不计入执行时限。

## 缓存与审计

稳定策略／环境字段位于动态证据和操作之前。仅同运行、配置、证据和取消上下文的相同进行中审核可共享计算。完成结果随即移除，各调用者仍重新核验来源。这不是可复用权限凭证。

审核卡独立显示策略、理由、耗时、输入／缓存／输出 tokens 和估算费用。命中来自 API 实测。模型可能误判，测试未误放不等于安全证明。见[历史评测](APPROVAL-EVALUATION.zh-CN.md)与[安全](SECURITY.zh-CN.md)。

## 通用证据与费用记录（2026-10-23）

自动审核保留最近及任务相关的用户授权与消息 ID，定时提示、工具输出不算人工授权。已知影响且有明确或必要任务授权的低／中风险动作可自动通过；缺乏授权或恢复证据的高风险、未知影响、敏感传输和持久安全变更仍需人工核对。审核 JSON 格式错误仅在原超时内修复一次格式，两次调用均计入用量；不反复请求模型推翻有效拒绝。

自动模式的 write_file、edit_file、apply_patch 在写入前提供范围内真实前后片段、哈希及截断标记，执行前复查文件是否改变。此机制是应用工具门禁，不是操作系统文件沙箱，也不保证阻止外部进程并发改写。命令走命令审核；审核根据目标、数据去向、进程归属、在途工作影响和可恢复性判断，不按应用或厂商特判。忙碌重启应先查明并等待空闲或采取有范围的优雅重启，不能凭空声称无影响。

已知零费用的媒体不再仅因未设置金额上限而强制人工确认；未知价格不视为免费。正常权限、用户生成意图与附件传输审核保留。本地地址也不证明服务不访问上游。

媒体服务可选配置明确的 USD 金额响应字段，或计费用量字段与每单位 USD。任务保存配置快照，结果区分“服务报告”“按用量估算”和执行前预估；不猜测任意 cost 字段含义，也不自动请求账户账单。仅返回二进制或通过独立账单接口结算的服务，尚需专门适配；当前不是自动同步全部厂商价格或最终账单对账。秒数、帧数、分辨率及输入素材费用必须以具体模型协议为准。

语言模型原有流式链路已请求末尾用量，并区分缓存命中、未命中输入和输出单价；本次额外保存 API 明确返回的未命中数。API 实测 token 不等于 API 实报金额，未配置价格仍显示未知。

验证使用合成费用响应、缓存数据、预算边界、文件差异／失效和格式修复测试；不将这些测试宣传为真实厂商完整计费或审批误判率验证。

## 转人工前的有限证据补查

有效独立审核可以为已获任务授权但仍缺少影响证据的动作返回 inspect／revise／wait。原动作没有开始，也没有获批；宿主将明确的“未执行，需要补证据”工具结果交回执行 Agent，由它在已有权限内补查、缩小方案或有界等待后复查。再次提交仍重新独立审核，不直接执行审核器建议的命令，不产生新权限，也不偷偷创建后台等待任务。

每轮最多三次补查机会，计数持久化；完全相同的审核证据不会反复补查，而进入原人工流程。缺少授权、严重风险、敏感传输、安全变更、强制人工规则、恢复不确定性、审核服务失败及授权变化均不走此回路。此功能减少可自行解决问题的打扰，不保证所有任务零人工；仍取决于执行模型和可用检查工具能否获取所缺事实。

公开参考：[OpenAI Auto-review](https://alignment.openai.com/auto-review/) 将执行与授权分离，给出拒绝原因并限制反复尝试；[Claude Code 权限模式](https://code.claude.com/docs/en/permission-modes) 将分类审核与全放行区分并保留回退阈值；[ChatGPT Agent 安全说明](https://help.openai.com/en/articles/11752874-chatgpt-agent) 保留高影响动作确认。这些是设计依据，不代表使用相同内部实现或达到相同自动通过率。Amadeus 保留确定性的授权及证据校验，也未复制其操作系统沙箱或生产评测。

## 2026-10-23：风险标签与实际授权

高风险启发式不再直接转人工，而是交给独立审核器核对。仅当用户明确授权覆盖目标及后果、影响已知且有界，并有已观察的可逆或恢复机制证据时才可自动通过。缺失恢复证据、不可逆、关键风险、敏感数据外传、安全设置变更以及强制人工规则仍不能走此路径。备份承诺不等于已验证备份，撤销本地文件不等于撤销发布或外传。原有上下文与文件变更复核仍生效。

参考 [Codex 公开自动审核设计](https://alignment.openai.com/auto-review/) 的独立风险与授权评估；这是本项目实现，不宣称复制未公开机制。

轮末展示父子任务合计输入、输出、已记录缓存占输入比例与估算美元费用。未知单价或缺失用量不当作免费，旧轮次不追填当前价格。手动价格优先；未配置价格的精确官方服务与模型可使用带有效期的官方价格快照，目前 DeepSeek 快照核对于 2026-10-23，有效至 2026-11-23（UTC）。通用时段规则按请求开始时间、UTC 时段、星期及已核对的当地节假日日历自动选价；轮末展示本轮实际使用的峰时／谷时档位，跨档位调用分别计算。费用不是服务商账单，逐调用账本保留使用的价格来源与依据。第三方转售地址不套用官方单价。来源：[DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)。

高风险且缺乏恢复证据时，可先进行只读补证，原动作仍不执行；补证沿用每轮最多三次及相同证据不重试的限制。通用价格日历来源：[国务院 2026 年放假安排](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)。
