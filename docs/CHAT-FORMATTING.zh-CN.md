# 对话排版与媒体

[English](CHAT-FORMATTING.md) | [简体中文](CHAT-FORMATTING.zh-CN.md) · [文档目录](README.zh-CN.md)

支持 Markdown 标题、列表、任务列表、表格、链接、图片、代码高亮及 KaTeX 公式。代码块支持复制、展开和收起；宽公式可以横向滚动。

## 中文粗体

对中文标点相邻、成对但未被标准 Markdown 识别的粗体增加兼容处理。代码、刻意转义的星号和流式输出中尚未闭合的片段保持原样，不修改保存的原始消息，也不尝试猜测修复所有错误格式。

## 带发言者的引用

这是通用标注，可用于访谈、会议、审查、故事或多角色讨论：

```markdown
> [speaker: 审阅者]
> 这项结论已有证据支持。

> [speaker: 作者]
> 我会据此更新实现。
```

也支持 `[角色: 名字]`。显示姓名和稳定配色；六色调色板可能重色，姓名才是身份依据。没有标签的普通引用不会被猜测归属，也不会自动转换成角色台词。

## 公式与交互预览

公式支持 `$x^2$`、`$$...$$` 和 LaTeX 的 `\(...\)`、`\[...\]`。KaTeX 不等于完整的 TeX 文档编译器。

标记为 `html` 或 `html-preview` 的代码块默认显示互动预览，可切换到同尺寸代码面板，代码在内部滚动。切换保留互动状态，重置按钮重新加载。可选择紧凑、标准、高三档高度，或纵向拖动调整。标记为 `mermaid` 的代码块支持本地渲染关系图、流程图、时序图、状态图和实体关系图，同样可以切换代码。Mermaid 使用严格模式和不绑定交互回调的 SVG 图片；解析失败时仍可查看源码。

预览采用不共享来源的 iframe，禁用同源访问、顶层跳转、弹窗和表单权限，并通过 CSP 限制资源加载及网络连接，不能读取宿主页面 DOM 或存储。它不是操作系统沙箱，不能保证资源限额或阻止所有形式的导航。不支持外部依赖、任意 Python 执行、安装包或完整开发服务器工程。普通 Markdown 中的原始 HTML 不直接执行。

## 媒体与语音

图片、视频和音频任务卡保留在首次出现的位置，后续进度或完成结果更新原卡片，不移动到新一轮底部。现有媒体卡可播放、下载、折叠；带音视频扩展名的本地对话媒体链接也可内嵌播放器，不自动把任意外部链接变成播放器。

麦克风图标位于**发送按钮旁边**。先在设置配置转文字服务，并允许浏览器使用麦克风。使用 localhost 或 HTTPS 下支持录音的浏览器。停止录音后选择上传转文字，结果进入可编辑草稿，不自动发送。这是语音输入，不是实时语音通话。

## 验证边界

当前回归基线见[验证说明](VERIFICATION.zh-CN.md)。真实无头 Edge 验证了默认预览、切换保留状态、同尺寸代码内部滚动、两种 Mermaid 图以及移动端宽度。类型检查及生产构建通过；未调用付费媒体服务。

## 互动结果

已完成的 Agent 回复中的 HTML 组件可以通过可选桥接接口提交结果：

```js
window.amadeus?.submitResult({
  title: '方案对比',
  data: { option: 'A', total: 42 },
});
// 也支持：{ title: '反馈', text: '结果内容' }
```

每次提交新增一条记录。用户可编辑记录、选择多条，将当前结果或所选结果追加到已有聊天草稿；只有点击正常的发送按钮后，模型才会收到。适用于多轮模拟、游戏、互动表单和计算器，不是骰子专用功能。已有组件需调用此接口才能回传结果。

工具栏按当前界面语言显示，提供预览／代码切换、高度选择、复制和重置；切换视图或语言保留组件状态。

宿主核对发送 iframe、不透明来源、实例标识和数据格式。结果属于组件自报数据，不是已验证证据或权限授权。标题最多 100 字符，结果正文最多 16,000 字符；每个挂载中的组件保留最多 20 条记录，超出时明确提示。移除记录后可继续提交；较大的批量结果需分批填入草稿。

待分享记录属于页面状态，不是持久存档：重置、刷新或卸载组件可能清除它们。已加入草稿的内容按普通草稿处理，已发送消息按普通对话保存。前端按钮不能保证永久只掷一次或防篡改。组件不能自动发送消息、调用工具或访问宿主存储。本次无需新增依赖或修改启动脚本；现有启动脚本会在前端源码变化后重新构建。

## 预览尺寸

HTML 和 SVG 默认“适应内容”，高度跟随内容变化、图片加载和可用宽度调整，不重置组件状态；代码视图仍可内部滚动。也可选择适应窗口、紧凑、标准和宽敞。长内容最多展开至 2400px 并明确提示，避免不可信组件无限撑长聊天；依赖视口高度或自带内部滚动的组件仍可能滚动。

只接受当前沙箱 iframe 和当前令牌对应的尺寸消息，保留不透明来源及限制性 CSP。尺寸消息不能提交互动结果或访问宿主工具。

## 声明式图表与对比卡片

使用语言名为 chart 的代码块，正文是 JSON，不是可执行 JavaScript。默认显示预览，可以切换代码、复制源码，并使用已有高度选项适应内容或窗口。图表跟随应用深浅色主题，宽表格可以横向滚动。

支持以下结构，均可添加 title 标题与 caption 说明：

- 条形图：{"type":"bar","title":"耗时","unit":" ms","data":[{"label":"之前","value":120},{"label":"之后","value":75}]}。可选 max 指定至少覆盖全部数据的刻度，支持零和负数。
- 折线图：{"type":"line","data":[{"label":"第一次","value":3},{"label":"第二次","value":7}]}。横轴为等间距类别；悬停查看数值，展开数据可查看全部标签与值。
- 流程卡片：{"type":"flow","steps":[{"title":"观察","detail":"收集证据"},{"title":"验证"}]}。
- 表格：{"type":"table","columns":["版本","结果"],"rows":[["A","通过"],["B","待验证"]]}。

实际关系连线、时序图、状态图及实体图仍使用 Mermaid；普通 Markdown 表格和隔离 HTML/SVG 预览继续支持。图表 JSON 会校验结构并转义标签。上限为 100 个数据点或表格行、20 列、50 个流程步骤、10 万字符源码；未完成或非法输入显示说明，仍可查看源码。可视化不等于验证证据，不应为了画图编造分数或概率。

## 本地媒体嵌入对话（2026-10-12）

可以让 Agent 展示授权项目目录中已有的图片、视频或音频。新增 `import_media({path})` 通过 FileScope 读取文件、保存副本，并嵌入当前这轮对话；不会回到用户待发送附件区。同一运行中相同名称和内容重复导入复用引用，导入本身不调用外部服务。

选择文件与拖拽上传也支持媒体。图片直接显示，音视频提供播放器、拖动进度和下载入口；默认不静音、不自动播放。支持识别 PNG/JPEG/GIF/WebP、MP3/WAV/FLAC/Ogg、MP4/M4A、WebM；具体编码能否播放取决于浏览器，失败时保留下载入口。本地媒体上传、导入、播放、检查与导出不设固定应用文件大小上限，使用流式读写控制内存；仍受磁盘空间、文件系统及浏览器能力限制。整图解码和服务商参考素材提交保留独立的 25 MB 处理预算，超出时原文件仍可保存、下载与导出，供缩放、切片或转码。大容器的音轨检查可能返回未知，不猜测是否有声。批量上传中单个文件失败不丢弃其他已成功附件。

两种入口统一使用 `attachment:<id>`：`inspect_media` 检查元数据，`read_image({mediaRef})` 向视觉模型传入图片像素，`export_media` 不覆盖地导出到项目，后续生成可通过 `generate_media.references` 引用，仍受服务商能力和正常审批约束。引用限定在本对话，新附件校验内容哈希。音视频能播放不代表模型已理解内容，转写与抽帧仍需单独的授权处理；不会把媒体说明当作转写文本导入知识库。

“适应内容”的 iframe 预览预留滚动条空间，按 100 毫秒合并高度通知，并忽略不超过 2 个 CSS 像素的变化，减少布局反馈抖动。明显的内容增减仍会更新高度。浏览器回归覆盖长中英表格、多种宽度与缩放，不代表所有用户自定义响应式页面都已验证。

## 可下载文档与文件

`register_artifact(path)` 默认将文件交付快照附到当前对话，返回需登录访问的 `downloadUrl`。卡片显示名称、类型、字节数、下载按钮及 SHA-256。支持范围内任意普通文件，包括 PDF、DOCX、PPTX、XLSX、Markdown、CSV、JSON、HTML、LaTeX 源码和 ZIP；交付现有文件无需外部上传或命令联网权限。`attach=false` 仅内部登记。修改工作区原文件不会改变已交付副本，新版本重新登记会得到新下载。删除对话时清理附件存储，并保留其他分支仍引用的文件。

`create_document` 生成真实文件、保存到工作区，并自动显示下载卡片：

| 格式 | 输入                                     | 生成方式                                              |
| ---- | ---------------------------------------- | ----------------------------------------------------- |
| DOCX | 标题及段落、标题、列表、代码、分页块     | docx                                                  |
| PDF  | 同上，A4 排版                            | Windows 已安装的 Edge；其他平台的 Playwright Chromium |
| PPTX | 每页标题、正文、可选演讲备注             | PptxGenJS，宽屏                                       |
| XLSX | 命名工作表，文字、数字、布尔值、空单元格 | ExcelJS                                               |

内置工具提供基础排版，不等于完整 Office 自动化或任意格式转换。XLSX 字符串不会作为公式执行。复杂样式、公式、图表、图片和其他专用格式可通过另行授权的工具生成，再用 `register_artifact` 交付。LaTeX 可生成并下载 `.tex` 源文件；编译 PDF 还需可用且已授权的 TeX 工具链。不能通过改扩展名冒充转换，也不能将文件生成成功说成内容与排版已经核验。

PDF 使用独立无头浏览器渲染经过转义的结构化内容，禁用脚本与资源请求，不读取用户浏览器配置；非信任模式需要批准固定渲染进程，不通过关闭浏览器沙箱兜底。缺少浏览器时明确报错。生成工具总输入不超过一百万字符，并限制页、块、单元格数量；这是生成资源预算，不是下载大小上限。文件快照与下载采用流式处理，无固定单文件大小限制；失败会清理快照，磁盘仍需有足够空间。

现有启动与首次启动入口按锁文件安装依赖。生成 DOCX/PPTX/XLSX 不要求安装 Microsoft Office。运行中的服务需要在任务结束后重启，才能加载更新的工具与 UI。
