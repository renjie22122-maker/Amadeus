# 安全模型

当前说明核对日期：2026-10-12。

## 本机服务与数据

Amadeus 是单用户本机回环服务，不是多用户部署。Host／Origin 校验、HttpOnly SameSite Cookie 和 CSRF 校验保护控制 API。Windows 配置使用当前用户 DPAPI；其他平台使用受限文件。同账号恶意进程和管理员仍可能访问数据，.data 与 .diagnostics 不应提交 Git。

FileScope 检查授权根、路径穿越、符号链接／目录联接、硬链接、元数据和私有存储。大小写归一检查有意义，但应用路径校验不是命令的 OS 隔离，也不是抗恶意并发文件锁。Skill、文档、记忆、截图、工具输出均是不可信上下文。

## 审批与隔离

只读模式禁止命令和写入；普通对话没有项目命令能力。Ask 要求审批具体命令。默认允许范围内文件工具写入；开启“文件写入审批”后，Trusted 之外的修改需批准。Trusted 由用户明确选择，其隔离子 Agent 初始使用 Ask。

新配置在 Windows 选择 AppContainer，其他平台选择 Docker；旧配置保留原后端。缺少前提时拒绝，不退回宿主。宿主命令有当前账号权限，工作目录不能约束其副作用范围。

Docker 默认非 root UID:GID 1000:1000，禁网、移除能力、限制资源、只读容器根，并挂载所选项目目录；屏蔽元数据目录，拒绝不安全链接和元数据指针。需要已安装镜像与运行中的引擎，本机尚未完成 Docker 隔离集成认证。

AppContainer 需要绝对 Python 路径。文件隔离模式允许宿主网络，严格离线还要求断网预检成功；本机此前未通过。原生执行拒绝含 .git/.agentdemo 的目录：选择性元数据拒绝 ACL 实测失败，因此不声称已经解决，应使用干净隔离副本。见[执行后端](MIGRATION.zh-CN.md)。

## 其他执行通道

MCP 可执行程序、浏览器和 Computer Use 使用单独配置的宿主权限，不受命令沙箱自动保护。公开 fetch_url 校验并固定公共 DNS 地址、复查重定向；浏览器域名规则独立，不是 DNS 固定式 SSRF 隔离。模型／embedding 端点可以是用户有意配置的本机服务。

操作规则可拒绝或要求人工，不授予更宽权限。注入提示只是启发式警告，不是完整污点分析。包签名验证用户给定的发布者密钥，不证明代码安全。

## 副作用与审批证据

等待审批无到期时间；已批准修改即将执行时才写副作用意图。确定未启动记为 not_started，超时可能仍未知。精确文件后像可自动核实；任意命令结果需证据，未核实项需用户确认／重试授权，不盲目重放。

自动审核仅在已授权的同模型连接路径下读取有限源码；另选审核器不会自动收到。审核失败转人工，绝不默认放行。见[自动审批](AUTO-REVIEW.zh-CN.md)。

回归测试证明执行过的契约，不是安全认证或正确性证明。

## 2026-10-12 边界审计

- 文件读取改用经过校验的文件句柄并限制实际读取量；发布使用独占临时文件句柄、刷新数据、复查父目录与文件身份，只清理身份匹配的临时项。已覆盖并发禁止覆盖发布，以及校验边界上的目录联接替换回归。
- **仍有 P0 限制：** Node 的跨平台路径发布与清理接口不等同于基于目录句柄的文件系统隔离。有权限重命名父目录的恶意进程仍可能竞争最后一步；这些测试不能证明不可绕过。应使用操作系统隔离，不要让恶意工作区进程与宿主文件工具并发修改目录。
- 未知执行后端、Docker root 用户及有歧义的挂载路径会在启动前拒绝。严格原生隔离必须返回断网预检凭据；进程在 spawn 事件之后报错属于结果未知，不能归类为确定未启动。
- 本机实测：Docker 不可用；严格 AppContainer 在请求的 echo 命令启动前返回 SANDBOX_PREFLIGHT_FAILED（无法确认断网）。未退回宿主执行。本轮**没有**完成 Docker 真实隔离或原生隔离成功执行的集成认证。
- 恢复引用绑定原始副作用、运行、对话和持久化命令／媒体作业。媒体回执可以证明提交已被接收，不能证明生成成功或验收通过。没有恢复协议的外部非幂等工具仍须核实，不能通用重试。
- 用户核实是可审计的人工陈述，不会冒充宿主验证成功；已结算的副作用不能被再次核实覆盖。
