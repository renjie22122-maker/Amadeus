## 对话与项目

普通对话使用独立聊天文件区，不是可以执行项目命令的工作区。项目支持最多 12 个互不重叠的文件夹，可在项目管理中增删。移除项目归档其访问入口，不删除磁盘文件；永久删除对话需确认，不删除项目文件。对话分支共享项目文件，与可写子 Agent 的隔离副本不同。

界面支持中英文、自定义助手名、自动字号及 25–150% 档位。支持复制对话／代码、回复反馈、轮次定位，以及上下文、用量、工作区和修改详情。步骤与已处理交互可折叠；任务板存在时显示计划。见[交互](INTERACTION.zh-CN.md)与[排版](CHAT-FORMATTING.zh-CN.md)。

## 模型与工具

连接支持 OpenAI 兼容 Chat Completions、Responses、Anthropic 和 Gemini 适配器。模型发现使用实际返回的元数据；未知字段保留配置入口，不视为已验证能力。推理等级取决于模型配置。图片经附件或 read_image 送给支持图片的模型；声明支持不等于端点实测成功。

Skill 按需加载，支持批量选择、来源／类别筛选及在告知目标模型后进行分类。导入不会授予工具、账号或依赖。受控环境准备、本地版本化技能包补充发现流程。见[工具](TOOL-ECOSYSTEM.zh-CN.md)。

## 团队与等待

可选择单 Agent、自动委派或优先协作；团队拓扑还提供主 Agent／工作者、宿主调度平级成员、创意平级讨论。宿主先检查依赖、资源、权限、隔离和容量，再按历史反馈等信号评分。

持久成员可继续原会话，不必每轮新建身份。可选恢复、有上限扩缩容、空闲退役和角色接管仍属于单宿主策略。创意消息是观点或虚构内容，不是验收证据。

后台命令与延后审批允许模型在等待时做独立工作；依赖结果的步骤必须等待。普通前台工具仍可能阻塞本轮执行。不同会话的准入限制分开，不需要额外派一个 Agent 专门等待。

## 知识库与记忆

普通对话共享记忆／资料库、各项目范围及私有会话文档分开。已授权文件夹自动维护支持增量解析、版本、OCR、向量和失败处理。本地多语言 E5 与外部 embedding 均可用；ANN 是本地索引算法，不是语言模型。见[记忆](MEMORY.zh-CN.md)。

## 媒体

独立连接覆盖图片、视频、音乐、语音合成、转录、3D 协议。需配置实际模型 ID、选项和密钥；协议支持不等于所有模型均实测。费用为估算，不是账单。

产物返回同会话媒体引用。list_media 找回旧任务；inspect_media 检查字节；read_image 查看图片；export_media 将原始字节复制到授权项目的新路径。服务商支持相应字段与格式时，图片／音频／视频可引用到后续生成。3D 可导出，但不是通用生成参考输入。录音转写进入可编辑草稿，不自动发送。见[媒体工具](TOOL-ECOSYSTEM.zh-CN.md)。

## 自动化边界

记忆默认值、资料维护、定时任务和团队恢复均需开启且受范围约束。定时任务要求服务运行。扩大资料范围、增加外部发送目标、账号接入和结果不明的破坏性操作仍需用户控制。自动审批不绕过隔离。见[安全](SECURITY.zh-CN.md)。

## 定时任务卡片

在 **后台任务 → 定时任务** 创建或编辑任务名称、内容、来源对话、首次执行时间（本机时间）、固定重复间隔（分钟／小时／24 小时天／7 天周）、可选的后台命令完成触发，以及通知策略。卡片提供暂停／启用、复制、删除和运行记录入口。运行中的任务不能编辑；暂停只阻止后续启动，当前执行仍可完成。失败或中断需先查看记录；复制会新建明确的任务，不重放原运行。

可选择 **在原对话继续** 或 **每次新建对话**。新对话继承来源的项目、模型、权限与设置，不复制聊天历史，因此任务描述应完整。来源归档、项目移除、模型发送目标变化或未核实副作用会阻止启动。运行 ID 与目标对话预先保存，重启不会重复创建同一轮执行。错过的周期合并为一次，并保持原间隔对齐；这是固定时长，不是随夏令时调整的日历规则。

通知是持久的 **应用内通知**，页面打开时会出现提示，之后可在后台任务查看和标为已读。支持每次结束、有变化／完成／异常、仅失败／需要处理、静默留记录。执行本任务的 Agent 可用 `report_scheduled_result` 报告无变化、有更新或完成；有意义通知模式下，成功的无变化报告保持安静，完成报告会在本轮成功后停止重复。报告来自模型判断，不等于独立验证的变化检测；缺少报告或失败不会被静默隐藏。运行记录可打开实际执行对话。

电脑和服务必须保持运行，不提供关机云端唤醒或系统推送。执行消耗模型额度，仍遵守普通权限与审批。旧任务兼容，无新增依赖、下载或首次启动配置；构建并重启服务、刷新页面即可启用，重启前应确认不会擅自中断工作。
