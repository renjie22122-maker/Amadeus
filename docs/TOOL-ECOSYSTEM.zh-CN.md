# 工具生态

## 通用 MCP 接入

设计参考：[Codex MCP 配置](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)、[Claude Code MCP 发现机制](https://code.claude.com/docs/en/mcp)、[DeepSeek Harness MCP 客户端](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/mcp/mcp-client/README.md)。本轮借鉴服务级超时、环境变量请求头、按需描述长度限制、明确的发现失败反馈和重名目录拒绝，不代表功能已全面对齐。

每个服务可设置 `startupTimeoutSeconds`（1–120，默认 20，适用于每次连接/发现请求）、`toolTimeoutSeconds`（1–600，默认 120）和 stdio 的绝对工作目录 `cwd`。`headersFromHost` 将请求头名映射到宿主环境变量名，可用于 API Key；协议和路由请求头保留。Bearer 令牌引用与 Authorization 请求头引用二选一。发现过程单独报告不可用服务，并保留其他已批准服务的结果；`complete: false` 表示结果不完整。取消、审批或权限失败仍终止发现。工具描述最多返回 4096 字符并标记截断，参数 Schema 保持完整。目录拒绝同名工具及超过 10000 个工具；调用时重新发现工具，不依赖过期定义，失败不重放调用。

设置 → MCP 服务支持本地 **stdio**（旧配置默认方式）和 **Streamable HTTP**。添加服务、选择方式、填写配置后手动启用。发现与调用仍经过现有审批、对话隔离和执行记录；工具描述或只读标记不授予权限。HTTP 发现连接远程服务，不启动本地程序。

HTTP 地址须为 HTTPS，本地回环地址可使用 HTTP；拒绝 URL 中的凭据、查询参数、片段和重定向。可选的 `bearerTokenEnv` 填 Amadeus 服务进程可读取的环境变量名。本地服务的 `envFromHost` 将子进程变量名映射到明确选择的宿主变量名，配置不保存密钥值。在服务启动环境中设置变量，变更启动环境后重启服务。这些措施不构成本地程序的沙箱。

`allowedTools` 是精确工具名白名单：省略表示开放服务目录，空数组表示不开放任何工具。发现与调用都执行限制；调用前按照服务声明的 JSON Schema 校验参数。运行进程可见的凭据变化会使连接缓存失效。失败不自动重放；取消不能保证远端尚未产生副作用。

GitHub 示例：`{ "id": "github", "name": "GitHub", "transport": "http", "url": "https://api.githubcopilot.com/mcp/", "bearerTokenEnv": "GITHUB_MCP_TOKEN", "command": "", "args": [], "enabled": false }`。令牌权限见 [GitHub 官方配置](https://github.com/github/github-mcp-server)。[Playwright MCP](https://github.com/microsoft/playwright-mcp) 按普通 stdio 服务填写已安装程序和参数，`--isolated` 可避免持久浏览器配置。请审核并固定服务版本；示例不会自动安装或启用。

其他服务只要传输方式和认证兼容，就能走同一配置入口，不需要按厂商编写专用逻辑。旧版独立 SSE 传输、sampling 和 elicitation 尚不支持。测试不代表每个第三方服务和原版部署环境均已验证。

### OAuth、后台任务与参考内容

HTTP OAuth 服务勾选“使用 OAuth 网页登录”，保存并启用后点击“开始登录”，打开授权链接。“检查登录状态”会显示预注册客户端需要的回调地址。客户端 ID 留空使用动态注册；预注册客户端须填写签发方，可引用客户端密钥环境变量。授权范围可选、以空格分隔。SDK 负责发现、PKCE 和刷新；回调通过十分钟有效、一次性的 state 和 issuer 校验绑定到未改变的配置。模型工具不发起网页登录，也不接收令牌。凭据单独存入私有文件，Windows 使用 DPAPI 加密，其他平台使用仅所有者可读写权限。“清除本机登录”删除本地凭据，不撤销提供方的授权。应用重启后需重新发起未完成的登录。不提供 CIMD 托管。

`mcp_call(background=true)` 在批准后仅启动一次外部调用，立即返回持久任务 ID。`mcp_job` 按对话列出、读取和等待任务，`mcp_cancel_job` 请求取消；后台任务页面也可查看结果与取消。模型可继续独立工作，新用户消息唤醒等待，任务收尾等待未完成的 MCP 调用。成功结果结清对应执行记录；取消、超时、连接失败和重启保留结果不确定状态，不自动重放。支持任务协议的服务使用 SDK 任务流，记录远端任务 ID、取得最终结果，取消时也尝试 `tasks/cancel`。调用受服务超时限制；已支持下述重启续接；任务中的 elicitation 尚未实现。内置浏览器/桌面适配器继续同步完成文件和图像交付。后台结果最多保留 256000 字符并标记截断。

重启恢复：保存远端任务 ID、协议版本、原始服务/凭据绑定及 HTTP 会话标识。正常退出先停止本地跟踪，不取消远端任务；启动时自动续查已有任务，后台页面“续接已有任务”或 `mcp_job(operation="resume")` 可在故障排除后再次跟踪。续接仅调用 `tasks/get`、`tasks/result`，明确取消才调用 `tasks/cancel`；不会发送 `tools/call`。并发续接合并到同一个任务，结果与成功执行凭证原子保存。短暂查询失败最多退避重试三次，之后保留记录等待手动续接；状态查询遵循服务的轮询间隔。恢复不会启动新的模型回合，结果可在原对话的任务记录和后台页面查看。

服务配置、环境凭据、OAuth 登录身份、项目和权限必须保持匹配；OAuth 自动刷新不会改变登录身份，重新登录则产生新身份。HTTP 会话标识仅保存在内部记录，不进入模型或后台 API。普通调用、未收到任务 ID、旧版缺少绑定的记录无法安全恢复；任务过期、服务器丢失任务、会话失效或需要交互输入时保留不确定状态，不重跑。stdio 仅在服务自己持久化任务时能续接，不保证子进程退出后工作仍存在。当前适配器明确支持 SDK 的 **2025-11-25 Tasks**，不冒充兼容 **2026-07-28 Tasks extension**；后者须独立协议适配。恢复仍有 32 个同时跟踪任务的上限，其余可手动续接。

设计参考：[Claude Code 的任务退出/恢复与配置绑定](https://code.claude.com/docs/en/mcp#exit-clear-or-resume-while-an-mcp-task-runs)、[MCP 2025 Tasks](https://modelcontextprotocol.io/specification/2025-11-25/basic/utilities/tasks)。[DSH MCP](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/mcp.md) 当前公开文档声明不支持任务式执行，因此不能将连接重连等同于任务恢复。`tests/mcp-recovery.test.ts` 使用真实 HTTP 和重开的 SQLite 验证有/无会话的续接、丢失任务、配置变化、并发续接和单次提交。

`mcp_content` 支持分页列出资源、URI 模板和提示模板，读取资源 URI（含展开的模板），按字符串参数获取提示模板。沿用审批和实时权限检查。URI 仅传给选定 MCP 服务，不直接读取本机文件或发起网页请求。模板消息作为标注来源的参考内容返回，角色字段不变成系统指令，也不授予执行权限。内容上限 128000 字符，截断显式标记。不提供资源订阅或自动执行模板。

设置页提供 GitHub、Playwright、Filesystem、Git、Chrome DevTools、Sentry、Brave Search、Fetch 八个默认禁用的示例，固定版本记录于[纯配置目录](../shared/mcp-examples.ts)。启用前请审核版本更新并替换目录占位符。GitHub 需要 `GITHUB_MCP_TOKEN`，Brave 需要 `BRAVE_API_KEY`，Sentry 需要用户 OAuth 授权；本地示例需要 Node.js/npx 或 uvx，浏览器示例还需要兼容浏览器。代码更新不修改应用配置或安装凭据。显式实测命令：`node --import tsx scripts/check-mcp-example.ts Fetch` 或 `Git`；会按需下载固定版本到运行器缓存，再执行一次公开网页读取或仓库状态查询。两项已于 2026-10-25 在此环境通过。OAuth/DCR/PKCE/刷新、资源/模板、任务流消费、审批和重启行为由测试服务覆盖，不表示已登录真实用户账号。

同一实测脚本也接受 `Filesystem`、`Playwright`、`"Chrome DevTools"`，没有 npx 时可加 `--pnpm` 使用 pnpm dlx。这三项也于 2026-10-25 通过，分别检查允许目录及独立无界面浏览器的标签/页面列表。这是连通与基础调用验证，不是全部工具认证。Chrome DevTools 示例关闭使用统计。界面实测脚本 `node scripts/check-mcp-ui.mjs`（可设置 `BROWSER_CHANNEL=msedge`）在临时应用中检查 OAuth 状态、示例导入和后台结果显示，不登录第三方账号。

## 发现与组合

search_tools 渐进暴露匹配定义，支持中英文关键词及可选仅本地 embedding 融合；本地失败明确回退。search_capabilities 合并范围内工具／技能／记忆／知识发现，不授予权限。

glob 与 UTF-8 字面 grep 保持 FileScope 并报告限制。read_json 返回结构化数据，read_file 带行号。batch_read_tools 最多 20 项并行安全读取、四工作者；tool_workflow 最多 12 步、布尔条件、前序结果引用、20 项循环，总调用最多 40。拒绝未来／原型引用、递归组合和任意代码执行；每个子调用保留审批／审计，部分失败不是事务。

transform_data 支持有界计数／字段投影／等值过滤／去重／求和（1,000 项／1 MB）。inspect_file_version 与 apply_patch 支持最多 20 个已有文件的哈希绑定精确片段，部分写入明确报告。Git 检查走普通命令后端，不使用特权子进程，不自动恢复或猜测作者归属。

## 浏览器与桌面

在设置 → 工具生态添加默认禁用的适配器，核对权限后开启。Playwright 在 Windows 使用已安装 Edge，其他平台需准备 Chromium。浏览器配置按会话隔离；可选保存 Cookie／本地存储，不等于保存完整标签页。重置／删除清理所属状态。

支持导航、点击、填表、按键、选择、等待、滚动、截图和保留弹出页。browser_tabs／select_tab／close_tab 使用上下文内稳定 ID。上传／下载桥接限制 10 MiB 与授权路径；上传需批准，下载不覆盖、不执行。非空精确域名白名单阻止重定向／WebSocket；空列表使用已批准宿主网络，不是固定 DNS 式 SSRF 隔离。

interaction_capabilities 不启动进程，只报告配置；enabled-unverified 不等于探测成功。Windows Computer Use 用 .NET Framework 编译器构建本地 C# 适配器，不修改 PowerShell 策略。支持窗口／UI Automation 枚举、截图、鼠标、输入、基本按键、滚动和拖拽。互斥锁串行输入；目标必须已在前台，失焦停止，不强行切窗。

无 windowId 时截图可见像素；有 ID 时用 PrintWindow 尝试遮挡窗口截图。最小化／无效／不支持时失败，不自动转为全桌面截图。有 20 秒时限和 1,600 万像素上限。GPU／受保护内容仍可能黑屏或陈旧，contentVerified 为 false。它是宿主桌面控制，不是自动 VM 隔离或所有应用的能力认证。

## Skills、技能包与 Hooks

技能按需加载，资源可物化；依赖通过获批的项目内 pip/npm 环境准备，禁用 npm 生命周期脚本。依赖就绪不证明完整技能可用，也不会自动获取账号。

支持本地包预览、哈希绑定安装／升级／回滚及停用，新修订默认禁用，保留源版本。agentdemo-signature.json 是兼容文件名；Ed25519 使用用户信任的 PEM 密钥验证原始 SHA-256 清单摘要，不认证代码安全。来源目录不是在线市场、自动远程下载器或 OAuth 生命周期。

Hooks 覆盖 Tool、Command、Compaction、TaskComplete、MemoryWrite 前后阶段，支持前置拒绝和审计。命令钩子仅用于工具／命令阶段，保留权限且阻止递归，每次外层调用最多八条钩子命令。Skill 不能启用宿主钩子。

## 来源、产物与策略

research_sources 最多收集六个公开 URL；crosscheck_sources 检查引文、模型指定的支持／反对立场、重复正文与域名数。来源不证明真假或发布者独立。有界压缩保留来源警告哈希，启发式注入警告不是完整污点跟踪。

产物登记路径／哈希／大小／类型／生产者；检查发现失效／缺失，停用不删文件。所有工具有审计和进度，命令另有流式输出；进度不虚构完成百分比。

操作规则只能拒绝或要求人工；专家角色限制继承的 Skill／工具。计划审核将同意绑定到任务板哈希／版本，不授予工具权。模型能力检查区分配置与端点实测。

## 生成媒体

list_media 找到同会话历史／当前任务，media_status 回执提供 media:jobId:outputId。inspect_media 查元数据与完整性，read_image(mediaRef) 发送规范化像素；export_media 将原字节写到授权项目新路径，拒绝覆盖／保护路径。不应仅因媒体位于私有存储而要求用户重新上传。

图片／音频／视频引用可进入获批生成字段，内联上限 25 MB，仍取决于服务商格式支持。3D 支持导出，不是通用参考输入。MP4 检查可读音轨是否存在，不保证可听或浏览器解码；其他／旧／不可读结果保持未知。HTTP 单段字节范围支持拖动播放，界面不默认静音。检查／导出不转码、不补造音轨、不发起付费生成。

见[互动排版](CHAT-FORMATTING.zh-CN.md)、[安全](SECURITY.zh-CN.md)与[验证](VERIFICATION.zh-CN.md)。仍待完善：可靠多文件事务恢复、带用户修改归属的 Git 恢复、远程市场生命周期、VM 自动准备和广泛桌面应用评测。

## 公开网页与协议配置

web_search 使用单独配置的 DeepSeek Messages 搜索通道，默认 https://api.deepseek.com/anthropic/v1，只接受结构化搜索证据，不把模型散文当搜索结果。默认时限 60 秒，不自动付费重试；辅助调用记录到当前运行并占用模型容量。fetch_url 读取公开文本和链接，不执行网页 JavaScript；命令网络仍由所选后端决定。

媒体适配器覆盖 OpenAI 兼容、fal.ai、Replicate、Gemini、ElevenLabs、Deepgram、AssemblyAI、Meshy、Tripo 和 MiniMax。MiniMax 直连端点为 https://api.minimax.io，语音需 voice_setting.voice_id；账号授权和具体模型选项以实际连接为准，不把适配器列表当实测模型列表。图片工具支持 PNG/JPEG/WebP/GIF，按字节识别后规范化到最多 640,000 像素／1 MiB，动画只取首帧。SVG/PDF/视频需先转成图片。媒体读取／导出另有 150 MB 输出边界；这不等于生成服务的尺寸上限。

技能包签名清单按路径排序，项为 {path,bytes,sha256}，路径使用正斜杠；排除隐藏／构建目录和签名文件。对该清单 JSON 的 SHA-256 原始 32 字节做 Ed25519 签名，signature 以 base64 保存。发布者公钥必须由用户信任，不自签即自信任。

## 本地媒体嵌入对话（2026-10-12）

可以让 Agent 展示授权项目目录中已有的图片、视频或音频。新增 `import_media({path})` 通过 FileScope 读取文件、保存副本，并嵌入当前这轮对话；不会回到用户待发送附件区。同一运行中相同名称和内容重复导入复用引用，导入本身不调用外部服务。

选择文件与拖拽上传也支持媒体。图片直接显示，音视频提供播放器、拖动进度和下载入口；默认不静音、不自动播放。支持识别 PNG/JPEG/GIF/WebP、MP3/WAV/FLAC/Ogg、MP4/M4A、WebM；具体编码能否播放取决于浏览器，失败时保留下载入口。本地媒体上传、导入、播放、检查与导出不设固定应用文件大小上限，使用流式读写控制内存；仍受磁盘空间、文件系统及浏览器能力限制。整图解码和服务商参考素材提交保留独立的 25 MB 处理预算，超出时原文件仍可保存、下载与导出，供缩放、切片或转码。大容器的音轨检查可能返回未知，不猜测是否有声。批量上传中单个文件失败不丢弃其他已成功附件。

两种入口统一使用 `attachment:<id>`：`inspect_media` 检查元数据，`read_image({mediaRef})` 向视觉模型传入图片像素，`export_media` 不覆盖地导出到项目，后续生成可通过 `generate_media.references` 引用，仍受服务商能力和正常审批约束。引用限定在本对话，新附件校验内容哈希。音视频能播放不代表模型已理解内容，转写与抽帧仍需单独的授权处理；不会把媒体说明当作转写文本导入知识库。

## 通用工作链（2026-10-13）

`inspect_work_capabilities` 列出当前权限可用工具，并区分计算环境已配置但未验证、缺失和被阻止。`inspect_tool_plan` 逐项检查具体工具名称、参数及前向依赖索引，不执行、不授予审批；会提示重复调用，但不能证明计划完整覆盖用户目标。工具选择指引要求保留不同的请求操作，不编造参数。

`run_python` 经现有审计的 `run_command` 执行，只允许已选择的 Docker 后端。代码以 base64 经过 Shell，镜像需包含 `python3`，审批期间后端改变则拒绝。继承离线网络、非 root 用户、资源限制和当前工作目录挂载；长任务保持同一后台任务，依赖结果前必须等待。这不是持久 Python 内核。CSV、JSON、ZIP、decimal、statistics 可用标准库处理；其他库需要预先安装到镜像中。

`extract_media_frames` 最多采样 8 个时间点并返回可供 `read_image` 读取的范围内路径。`extract_media_audio` 每次最多抽取 10 分钟的单声道 16 kHz WAV，并记录实际时长和请求起点。会话媒体先导出；抽出的音频先导入，再使用 `transcribe_media`。转录沿用媒体审批，上传前复核配置与权限，并绑定可恢复的媒体任务。25 MiB 上传限制明确报错，大音频先分段而非静默截断。供应商不一定返回逐句时间戳，调用方需保留分段起点；抽帧不等于完整视频质量验证。

`read_document` 通过 FileScope 读取字节快照，用原有固定解析器在 120 秒无页面／OCR 分块进展期限（PDF 总时限 30 分钟）／768 MiB V8 堆限制内解析，返回文本及分页偏移。PDF／图片可调用本机 Windows OCR，其他平台不保证有 OCR。解析器本地运行，需要项目和执行权限；资源限制不等于 OS 沙箱。取消会停止解析工作进程，不上传文件。当前翻页会重新解析快照，尚非持久文档分析会话。

HTTP 错误或正文过少的页面返回明确的浏览器接续指引。Agent 发现已启用浏览器，仍执行原 MCP／网络审批，不静默扩大权限，也不把抓取失败当作浏览器一定成功的证据。

`set_response_contract` 为当前运行记录用户要求的文本、单行、数字或 JSON 格式及可选前缀。运行时检查最终格式，最多允许两次修正，保留被拒的原输出，不自动删标签，也不自动重放工具。持续失败作为可恢复协议中断；收到新的用户输入后清除契约。普通对话不强制格式。它验证表示形式而非答案真假，且依赖模型声明用户要求；只测首个回答的评测不覆盖这条修正流程。

可选安装：Docker 运行后执行 `Setup-Analysis.cmd`，再在设置里选择 Docker 和 `amadeus-analysis:local`。镜像提供 Python 标准库及 FFmpeg。安装需要下载，不自动授予权限，也不随首次启动强制运行。不增加 Node 依赖。正在运行的冻结评测保持不变，增强能力后的对比须另建协议和结果目录。

本轮验证：完整本地套件 456 项通过、3 项跳过，后续针对性测试也通过。用已有 Python 镜像实测了离线／非 root Docker 计算及精确产物落盘。该镜像没有 FFmpeg。另用宿主已安装的 FFmpeg 对合成片段实测通过抽帧、1 秒音频分段及缺失编解码器拒绝；这不代表该 Docker 镜像内已具备 FFmpeg。外部转录适配器采用测试桩验证，未发起付费真实转录。文档分页返回 SHA-256，后续页传 expectedSha256 可拒绝源文件变化。审批收到的是从实际命令严格解码的 Python 源码，不信任另行填写的代码提示。

## 按任务发现技能与可响应消息的命令等待

Runtime 从启用目录按任务相关性推荐最多 12 个技能元数据（含中英文发现提示），不再只展示最前面的已选条目。推荐不加载正文、不执行技能；模型判断适用后调用 `read_skill`，再读取当前操作所需参考文件。不相关的任务无需使用技能。已选名称最多展示 100 个并说明省略数量；`find_skills` 仍可分页搜索全部启用目录。用户追加要求会刷新推荐。匹配属于启发式，不是经过校准的语义路由。

`inspect_skill_readiness` 将本轮读取记录与当前技能正文、最多 20 个显式指定参考文件比较，区分未读、已变更和不可用。它只检查提供的参考清单，不证明参考覆盖完整、实现正确、依赖可用或获得权限。技能辅助操作执行前仍需核对真实工作流/API 输入并保留用户批准的资产；读过指南不代表完成验证。

托管命令让出等待时保留同一进程和执行时限；即使 `yieldAfterSeconds=0`，新用户消息也能释放等待。收件箱检查避免通知早于监听时丢失唤醒。批量调用遇到让出或新消息后延期未启动操作；工作流遇到仍运行的命令停止后续步骤并保留回执。先处理新要求、等待原任务，再重新判断未执行工作，不自动重放或取消。此机制不能抢占任意阻塞 MCP 调用，也不能抢占没有托管等待的外部任务；Hook 完成前不会放行依赖它的副作用。

无需新增依赖、迁移配置或修改启动脚本。现有启动与首次启动脚本会重建变更源码；重启服务后生效。

设计参考：[Codex 技能渐进加载](https://learn.chatgpt.com/docs/build-skills)、[Claude Code Skills](https://code.claude.com/docs/en/skills)。不宣称完整兼容它们的调用控制或权限字段。

OpenAI Chat 与 Responses 的工具定义对所有提供商（包括本地兼容端点）采用稳定的工具名和对象键排序，枚举及元组数组保留语义顺序。稳定序列化不代表提供商支持缓存，也不保证缓存命中。

## 能力通用化审计（2026-10-19）

本轮逐文件核对了媒体设置→工具/HTTP 入口→参考转换/流式代理、本地语音安装→健康检查/启动→试听、RAG 命令行连接选择，以及技能元数据→自动推荐/find_skills 调用链；另对 server/shared/src/scripts 扫描应用、项目和评测名称分支。这是重点调用链审计，不是全仓逐行或第三方技能安全认证。

媒体设置新增明确的 `capabilities`：WAV NDJSON v1 流式朗读、可选模型参考限制（`maxPerField`、`maxTotal`、`arrayFields`）。流式适配器使用配置的模型/端点及同源健康接口，仅允许 HTTPS 或字面量回环 HTTP，禁止重定向；能力绑定地址、模型、协议、类型，更换后重新确认。普通 OpenAI 二进制/SSE 音频流不属于此协议。旧版内置默认语音连接进行窄范围迁移，不按未知服务的名字推测能力。参考转换另外执行应用预算：合计 64 个句柄、解码后总计 100 MiB、单文件 25 MiB。这些是资源保护，不是模型输入能力；模型限制留空代表未知。限制针对托管参考句柄，原始提供商 options 仍由对应提供商验证。额外数组字段声明避免仅凭英文复数猜测字段形状。保留实际的模型协议适配和 CosyVoice 参考音频 30 秒硬上限。

自动任务推荐与 `find_skills` 结合词法和本地语义排序（RRF），仅编码已启用技能的名称/描述，不读取正文或禁用技能。支持内置 embedding 与配置的字面量回环 embedding 服务，不向外部提供商发送技能元数据。自动发现预算 8 秒、显式搜索 15 秒，失败或超时带原因回退词法。每批 16 条、缓存最多 512 个向量、仅保留前 30 个语义候选，不保留全目录向量矩阵。排名不代表适用性证明或置信度，仍由模型判断是否需要并按需加载，不强制每轮使用技能。中英关键词表保留为兜底辅助，不充当语义引擎。

已知边界：配置的模型限制是用户声明，不是提供商认证；其他流式协议仍需适配器；外部语义技能索引不会被隐式授权。服务默认值、资源保护和模型协议规则不等于项目特例答案。本次扫描未发现 benchmark 答案分支，不代表所有源码和第三方扩展都已被认证。
